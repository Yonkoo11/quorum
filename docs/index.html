Quorum

A swarm of security lenses that never talk to each other. Sibyl Memory is the only channel between them.

Two lenses. One finding.

No lens can publish a finding on its own. A finding becomes real only when two lenses that work from different evidence arrive at the same conclusion, and the count of who agreed lives in memory, not in any agent's head.

Six independent lenses read Solidity source. Once a pattern is confirmed, the swarm recognises that idiom on sight in a completely different contract, in a completely different session, from a single sighting.

Delete the memory layer and there is no swarm left. Just six programs that each shout once and forget.

A single detector that reports everything it sees is noise. Six of them are six times the noise. Quorum pairs its lenses two per risk, and each pair reasons from different evidence: for reentrancy, callorder-lens sees an external call precede a state write, guard-lens sees value move out with no reentrancy guard.

Agreement is signal. Disagreement is kept as a candidate and never published. Run Quorum against audited production contracts and it mostly holds its tongue. On Aerodrome's Router, WETH9 and a Compound proxy it confirms nothing and files eleven candidates. That is the intended behaviour, not a failure to find bugs.

Where memory is load-bearing

Four call sites in one file carry the whole product

What breaks without itWritten atRead atTier
Agents duplicate each other's work. A lens claims a (contract, lens) unit; a peer that finds it claimed does not scan it. claim_work same call HOT state/
Quorum can never be reached. Corroboration is accumulated across lenses, processes and sessions. A lens has no idea who else agreed; memory does. record_sighting swarm.py:74 WARM entities/
Nothing is ever recognised again. A confirmed idiom becomes swarm knowledge and is matched on sight in later sessions, on contracts the swarm has never read. promote known_pattern REFERENCE reference/
Human corrections evaporate. Retire a finding once and no later session reports that shape again. retire is_retired ARCHIVE archive/

Every read and write is in quorum/memory.py. Every sighting, promotion, suppression and on-chain claim is also appended to the COLD journal.

Publishing costs.
Scanning does not.

Each claim burns 1,000 QUORUM through the token contract's own burn(uint256) on Robinhood Chain before the Base claim is written. Destroyed, not paid to anyone.

quorum verify checks both halves. A claim whose fee was never burned does not verify.

Once a claim is paid, its owner can reveal the pattern and any other swarm can import it. A pattern nobody paid to publish never enters anyone's memory.

run, swarm, recall, retire and --no-memory never touch the token. tests/test_token.py asserts that.

How to run it

On your own machine

Python 3.10 to 3.13. If python3 -m venv fails, the uv path avoids it.

No API key needed to pull verified source from Base.

git clone https://github.com/Yonkoo11/quorum && cd quorum

python3 -m venv .venv && .venv/bin/pip install -e .   # or:
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -e .

.venv/bin/quorum run --targets fixtures/*.sol   # the swarm learns
.venv/bin/quorum run --no-memory                # the deletion test
.venv/bin/python -m pytest tests -q             # 16 tests

Also: fetch, swarm, recall, retire, attest, verify, reveal, import, status. Attest needs BASE_RPC, QUORUM_TOKEN_RPC or the public Robinhood RPC, and DEPLOYER_PRIVATE_KEY.
